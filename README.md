# ProgramProwess
ProgramProwess is an analytical program which takes in user programming data and allows said user to have a stored sheet of their progress.
## Features
- Storing date, time spent coding, languages used, improvements, and struggles
- Dedicated datasheet to view, add, or delete entries
- Summarizer which computes current improvements and struggles
## How To Run
Using Google Colab, load this program and add in a datasheet that is formatted as shown in the program itself.
